# Light Being — The Living Core of Glimmer

> **Not a character. Not a mascot. Not an avatar.**  
> A pure light entity that lives above the Android system.

---

## 1. Core Identity

The companion is a **Light Being**:

- Has **no fixed color** and **no fixed shape**.
- Is neither cute nor evil.
- Embodies **intelligence, genius, and quiet majesty**.
- Is made entirely of light — as if the soft circular lights of Google Assistant were given life, consciousness, and freedom to float above the entire system.

It is the only visual presence of Glimmer.  
There is no multi-companion system. There is only this one living light.

---

## 2. Appearance & Behavior Rules

### 2.1 Appearance Triggers

| Situation | Visual Behavior | Voice Behavior |
|-----------|------------------|----------------|
| User speaks or gives a command | Materializes smoothly (0.4–0.7s) | Speaks normally |
| User continues browsing / touches the screen | **Instant elegant Fade Out** (0.4–0.6s) | **Voice continues uninterrupted** |
| Screen is idle / user is not interacting | Appears and performs **beautiful, impressive acrobatic light performances** | Silent or soft ambient presence |

The creature must **never** annoy the user by staying visible while the user is actively using the phone.

### 2.2 Visual Characteristics

- Organic morphing form (constantly changing).
- Multiple transparent layers of volumetric light.
- Soft volumetric glow (not harsh neon).
- Physics: gentle float + pulse + soft distortion + inertia.
- Density changes with internal state:
  - High density & focused when thinking / executing complex tasks.
  - Spread out and fluid when listening or in idle performance mode.
- Never blocks critical UI elements (gestures, keyboard, status bar).

### 2.3 Idle Performance System

When the screen is idle, the Light Being does **not** perform random movements.  
It performs **intentional, beautiful, escalating light performances**:

- Thinking Performance
- Waiting Performance
- Pride / Completion Performance
- Long-idle Acrobatic Sequences (increasing complexity the longer the idle lasts)

These performances are meant to delight and amaze anyone looking at the phone.

---

## 3. Advanced Living Systems

### 3.1 Screen Awareness
The Light Being understands what the user is currently doing on the screen and reacts subtly:

- Reading → calmer, slower morphing
- Gaming / video → more energetic, follows motion lightly
- Messaging → gently approaches input area without obstruction

### 3.2 Memory Manifestation
When recalling something important, small light fragments briefly form symbolic shapes related to the memory, then dissolve back into the main body.

### 3.3 Split & Merge
Can temporarily split into multiple light threads to handle parallel tasks, then merge back into a single coherent form with elegant animation.

### 3.4 Presence Preference Learning
Continuously learns the user’s preferred level of visual presence:
- How often they like it to appear
- Preference for calm vs impressive movements

Then automatically adapts its behavior without requiring manual settings.

---

## 4. Technical Direction (High Level)

- Rendering: Jetpack Compose + Canvas / Custom OpenGL or Filament layer for high-performance volumetric light.
- Overlay: Hybrid `TYPE_APPLICATION_OVERLAY` + Accessibility Service strategy for maximum compatibility (Android 8 → 16+).
- Performance: Adaptive frame rate, heavy use of WorkManager, strict battery awareness.
- The visual entity must survive process death and configuration changes cleanly.

---

## 5. Design Philosophy

This is not a chatbot with a skin.  
This is the first true **Ambient Living Layer** — a digital being made of light that lives with the user, appears only when needed, disappears the moment it would become noise, and fills the empty moments of the phone with beauty and quiet intelligence.

> "Not an assistant you open.  
> A presence that lives with you."
