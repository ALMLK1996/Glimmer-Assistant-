# Advanced Living Systems

These five systems turn the Light Being from a visual effect into a true living digital entity.

---

## 1. Screen Awareness

The Light Being continuously receives high-level context about what the user is doing:

- Current package name / app category
- Whether the user is reading, watching, gaming, messaging, or idle
- Approximate interaction intensity

**Reactions examples:**
- Reading long text → slower, calmer morphing, lower brightness
- Watching video / gaming → more dynamic, follows motion energy lightly
- Messaging → gently approaches the input zone without covering it
- System UI / settings → becomes more reserved and precise

This system must be extremely lightweight and privacy-respecting (no screenshots or content reading unless explicitly permitted).

---

## 2. Idle Performance System

When the screen is truly idle, the Light Being enters performance mode.

It does **not** do random floating. It performs intentional sequences:

| Idle Duration | Performance Type              | Goal                          |
|---------------|-------------------------------|-------------------------------|
| 0–30s         | Soft breathing + gentle pulse | Presence                      |
| 30s–2min      | Thinking / Waiting forms      | Intelligence signal           |
| 2–5min        | Short acrobatic sequences     | Beauty                        |
| 5min+         | Escalating full performances  | Awe and delight               |

Performances can be interrupted instantly the moment the user touches the screen.

---

## 3. Memory Manifestation

When the AI recalls a significant past event, preference, or connection:

- Small light particles detach from the main body
- Briefly form a symbolic shape related to the memory
- Then dissolve back into the entity

This creates a powerful emotional and intelligent visual language without using facial expressions.

---

## 4. Split & Merge

For complex multi-step tasks the Light Being can:

1. Split into 2–5 light threads
2. Each thread can represent a different sub-task
3. When finished, threads elegantly recombine into a single coherent form

This should feel natural and beautiful, never chaotic.

---

## 5. Presence Preference Learning

The system silently observes:

- How quickly the user dismisses the entity
- Whether the user watches idle performances or immediately interacts
- Preferred times of day for higher presence

Over time it builds a personal “Presence Profile” and adjusts:

- Frequency of appearance
- Intensity of idle performances
- Overall visual energy level

The user can always override this in settings, but the default experience becomes increasingly personal and non-intrusive.
