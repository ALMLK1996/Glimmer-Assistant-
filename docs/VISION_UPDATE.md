# Vision Update — August 2026

## Major Decision

The multi-companion character system (Nox, Zuri, Luna, Gaia, Seraph, Elder, Dawa, etc.) has been **permanently removed**.

Glimmer now has a single, definitive living entity:

### The Light Being

- A pure light entity with no fixed color or shape
- Intelligent, genius-level, and majestic (neither cute nor evil)
- Appears only when the user interacts with it
- Instantly disappears the moment the user continues browsing (voice continues)
- When the screen is idle, it performs beautiful, impressive acrobatic light sequences that delight the viewer

### Advanced Systems (Core)

1. **Screen Awareness** — understands what the user is doing and reacts subtly
2. **Idle Performance System** — intentional, escalating light performances
3. **Memory Manifestation** — visual memory echoes made of light
4. **Split & Merge** — can divide into light threads and recombine
5. **Presence Preference Learning** — learns how much visual presence the user prefers

---

All humanitarian, legal, privacy, ethics, and impact vision remain fully intact and are stronger than ever.

This pivot makes the product clearer, more focused, more technically ambitious, and more unique in the history of mobile software.
