# Contributing to Glimmer

Thank you for wanting to help build the first true Ambient Living Layer.

## Core Vision (Non-Negotiable)

Glimmer has **one** visual entity: a pure **Light Being**.

- No multi-character / multi-soul system.
- The Light Being is intelligent, majestic, and made of light.
- It appears when needed, disappears instantly when the user is browsing, and performs beautiful acrobatic light sequences when the screen is idle.

All contributions must align with this vision.

## How to Contribute

1. Open an issue first for significant changes.
2. Keep pull requests focused and well-described.
3. Follow Kotlin + Jetpack Compose best practices.
4. Prioritize battery life, compatibility (Android 8+), and privacy.
5. Document any new system clearly.

## Priority Areas

- Light Being rendering & physics
- Idle Performance System
- Screen Awareness
- Overlay stability across Android versions
- On-device AI integration
- Accessibility & system control
- Battery optimization

## Code Style

- Kotlin only for application code
- Clean Architecture + multi-module
- Meaningful KDoc on public APIs
- Zero tolerance for “TODO” left in production paths

## Legal & Ethical

All contributions must respect the Constitutional Principles, Privacy Policy, and AGPL-3.0 license.
